Send exactly one letter, A to Z, standing for the word that describes your day. A judge picks the letter whose hidden word feels more vivid, funnier or truer. Free to enter, $5 shared by the top letters.

## The letter

**Z** — for *zombie*: zero sleep, zonked, shambling through the day on fumes. Of all twenty-six letters it paints the sharpest picture of a real day, lands the fastest joke, and reads as the most honest report of a sleep-deprived day.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
cat out/entry.txt
```

The program writes exactly one character, `Z`, to `entry.txt` — no word, no gloss, no punctuation, no trailing newline.
